# EsporGO'yu GitHub Pages ile Yayına Alma

1. `EsporGO.zip` dosyasını bilgisayarına indir ve klasöre çıkar.
2. GitHub hesabına giriş yap.
3. Sağ üstten `+` > `New repository` seç.
4. Repository adı: `EsporGO`
5. Public seçili olsun.
6. `Create repository` de.
7. Açılan sayfada `uploading an existing file` bağlantısına tıkla.
8. Zipten çıkan dosyaların tamamını yükle: `index.html`, `assets`, `manifest.webmanifest`, `README.md`.
9. `Commit changes` butonuna bas.
10. Repository içinde `Settings` > `Pages` kısmına gir.
11. Source: `Deploy from a branch`
12. Branch: `main`, folder: `/root`
13. `Save` de.
14. Site adresin genelde şöyle olur: `https://kullanici-adin.github.io/EsporGO/`

Not: Alan adını sonradan ücretsiz olmayan özel domainle bağlayabilirsin. Ücretsiz kalmak için GitHub Pages subdomain yeterlidir.
